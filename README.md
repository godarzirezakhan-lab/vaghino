# ورقینو | Vaghino

پروژه یکپارچه فروشگاه کتاب دیجیتال با Next.js، TypeScript، Tailwind CSS و Supabase.

## امکانات موجود در این پروژه
- فروشگاه کتاب با جست‌وجو و دسته‌بندی
- حساب کاربری با ایمیل و رمز عبور
- پنل نویسنده برای ارسال کتاب، توضیحات، جلد و فایل کتاب
- وضعیت‌های پیش‌نویس، در انتظار بررسی، منتشرشده و ردشده
- پنل مدیریت برای بررسی و انتشار/رد کتاب‌ها
- صفحه مطالعه کتاب با متن یا محتوای فصل‌ها
- دانلود فایل کتاب برای کتاب‌های منتشرشده
- گزارش کتاب، نشانک‌های ساده و ثبت پیشرفت مطالعه
- ساختار PostgreSQL و سیاست‌های دسترسی RLS
- رابط فارسی راست‌چین و واکنش‌گرا

## پیش‌نیاز
- Node.js نسخه 20 یا بالاتر
- حساب Supabase
- برای آنلاین شدن عمومی: حساب میزبانی سازگار با Next.js مانند Vercel

## راه‌اندازی محلی
1. فایل `.env.example` را به `.env.local` کپی کنید.
2. در Supabase یک پروژه بسازید.
3. فایل `supabase/schema.sql` را در SQL Editor اجرا کنید.
4. از تنظیمات پروژه، Project URL و anon/publishable key را در `.env.local` قرار دهید.
5. در بخش Storage دو باکت `book-covers` و `book-files` بسازید. هر دو را Private/Public مطابق راهنمای پایین تنظیم کنید.
6. در ترمینال:
   ```bash
   npm install
   npm run dev
   ```
7. مرورگر را روی `http://localhost:3000` باز کنید.

## تنظیم متغیرهای محیطی
`NEXT_PUBLIC_SUPABASE_URL` و `NEXT_PUBLIC_SUPABASE_ANON_KEY` را پر کنید.
کلید `service_role` را هرگز در متغیرهایی با پیشوند `NEXT_PUBLIC_` قرار ندهید و در کد سمت مرورگر استفاده نکنید.

## ایجاد مدیر
پس از ثبت‌نام مدیر، شناسه کاربر را از Supabase Authentication کپی کنید و در SQL Editor اجرا کنید:
```sql
update public.profiles set role = 'admin' where id = 'UUID-USER';
```
هرگز نقش مدیر را از فرم عمومی کاربر قابل انتخاب نکنید.

## Storage
برای نسخهٔ اولیه می‌توانید `book-covers` را public و `book-files` را private قرار دهید.
برای دانلود خصوصی، در نسخهٔ تولیدی باید لینک امضاشدهٔ کوتاه‌عمر از سمت سرور صادر شود. نمونه فعلی دانلود را برای فایل‌های public پشتیبانی می‌کند؛ تنظیم private storage نیازمند افزودن endpoint امضای لینک است.

## انتشار آنلاین
- پروژه را به GitHub منتقل کنید.
- در Vercel ایمپورت کنید.
- همان متغیرهای محیطی را در Project Settings اضافه کنید.
- دامنه و URLهای مجاز ورود را در Supabase Auth تنظیم کنید.
- در Supabase Auth، ایمیل تأیید و محدودیت‌های ضد سوءاستفاده را فعال کنید.

## پرداخت
پرداخت واقعی به درگاه سازگار با کشور، حساب تجاری و تأییدیه ارائه‌دهنده نیاز دارد. این نسخه قیمت‌گذاری و برچسب رایگان/پولی را نگه می‌دارد اما عمداً پرداخت جعلی یا تأیید خرید ساختگی ندارد. پیش از فروش واقعی، درگاه و جدول سفارش/وب‌هوک معتبر اضافه کنید.

## بررسی محتوا
بررسی خودکار این نسخه، قواعد پایه‌ای برای محتوای خالی/نامعتبر و فراداده دارد. این جایگزین بررسی انسانی، فیلتر حرفه‌ای یا مشاوره حقوقی نیست. مدیر باید آثار را پیش از انتشار بررسی کند و کاربران امکان گزارش دارند.
